THE NEXT DOOR — GITHUB PAGES PACKAGE
Author: Jatin Tomar

Upload the contents of this ZIP to the root of a GitHub repository, or extract
it and upload the files and chapters folder. Enable GitHub Pages from the
repository's Settings > Pages.

The website includes the complete 18-chapter manuscript in chapters/.
index.html is the landing page and reader. Keep the chapters folder, styles.css,
and script.js alongside index.html.

The chapter text has been transferred from the supplied PDF. Only paragraph
spacing and obvious PDF extraction artefacts have been normalized.
